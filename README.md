# Codex Skills 与实践案例

把一次实际项目里的判断、技术取舍和验证方法，整理成其他人能够理解、运行和迁移的参考资料。

本仓库当前收录的是**案例文档与最小代码示例**，并非可直接安装的 Codex Skill，也不是完整生产应用。真实业务数据、成员名单、部署账号与凭据不在仓库中。

## 快速验证

需要 Node.js **22.18.0 或更高版本**；推荐使用仍受维护的 Node.js 24。示例没有第三方运行依赖，不需要执行 `npm install`。

```sh
npm test
npm run demo:contract
```

`npm test` 先检查发布目录中的常见敏感标识及不应出现的产物，再执行两个案例的测试。该检查不是完整的秘密检测或安全审计；新增资料仍须人工复核。

原生 Node.js 的 TypeScript 类型擦除只负责运行可擦除语法，不做类型检查，详见 [Node.js 官方说明](https://nodejs.org/api/typescript.html)。

## 如何阅读这些案例

1. 先读各案例的 README，了解可运行范围与不包含的部分。
2. 再读架构和经验文档，区分原应用实现、平台能力、设计建议和未验证事项。
3. 使用合成数据运行测试，再针对自己的数据治理、登录服务、部署环境与规模做适配。

这些案例不能证明任何预测的实际准确率，也不能保证某个工作区具备跨工作区分享、外部邀请或公开发布能力。托管平台功能须在目标账号中核实。
